A tiny Python program that writes one line to /output/entry.txt for make.fun's One Line, One Chill bounty: the single scariest sentence you can write, under 200 characters, in one breath. The line is a fixed string, so every run writes the same bytes.

## Run it

```sh
python3 main.py
```
